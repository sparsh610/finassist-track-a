`scripts/run_pipeline.sh`). To redo a stage, delete its output (e.g. `outputs/merged/` to re-merge).

## 6. Decisions made (and why)
- **Evidence recall replaces doc recall.** Every page has unique metadata, so with the metadata filter doc
  recall is trivially 1.0. Evidence recall checks the gold operands / answer span are in the top-4 chunks.
- **`source` targets are short citations** ("table row: net revenue"), median 49 chars. They used to be up
  to 300 chars of verbatim text cut mid-word, which made the quantized model copy pages until the
  384-token limit truncated the JSON. Dataset re-frozen; only `source`/`target`/`messages` changed.
- **Schema-constrained decoding** on the served model (`serving.constrained_decoding: true`): `source`
  capped at 160 chars. Not applied to the LLM judge.
- **Serving on laptop / Colab / friend's machine = llama.cpp GGUF Q4_K_M + Ollama** (`SERVE=ollama`).
  Ollama 0.40 cannot quantize Qwen2 itself (MLX only) or quantize a GGUF, so llama.cpp's
  `convert_hf_to_gguf.py` + `llama-quantize` make the file and Ollama serves it. vLLM + AWQ stays for the IIT box.
- **fp16 on pre-Ampere GPUs (T4).** `torch.cuda.is_bf16_supported()` is True on a T4 via slow emulation;
  `llm/backends.py:cuda_dtype()` checks compute capability instead.
- **Merge offloads to disk** (`outputs/merge_offload`): a 16-bit 7B model doesn't fit a T4 or Colab RAM.
- **Repo private**; Colab clones it with a `GITHUB_TOKEN` secret. `.gitattributes` forces LF (shell scripts
  must run on Linux) and keeps `*.jsonl` byte-exact (manifest hashes).

## 7. Problems hit and how they were solved
| Problem | Cause | Fix |
|---|---|---|
| Jobs "restarted for no reason" | Windows Update forced reboots after active hours end (23:00) | Resumable `run_pipeline.sh`; pause updates during long runs |
| Retrieval eval stalled, empty output | Shared CPU with another eval; stdout buffered and lost | Run one job at a time; unbuffered, per-variant saving, `--resume` |
| Pipeline killed (low memory) / died silently | Claude Code reaped the background shell; then broken pipe killed bash | Script logs to `outputs/logs/pipeline.log` itself; launched detached |
| Duplicate leaderboard rows | Old and new pipeline ran at the same time | Deduplicated; only one runner at a time |
| DPO crashed | Hard-coded CUDA 4-bit/bf16, wrong adapter path, ignored `tracking: none` | Follows compute profile like `qlora.py` |
| Quantize failed | Ollama 0.40 changes (see decisions) | GGUF via llama.cpp, then Ollama |
| Served JSON truncated (0.6 validity) | Verbatim `source` training targets | Short citations + prompt rule + constrained decoding |
